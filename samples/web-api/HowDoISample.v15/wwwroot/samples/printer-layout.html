Print a map

A zoning plan sheet, laid out on the server. The map is one element on the paper; the title block, legend, scale bar, north arrow, parcel table and notes are printer layout layers placed in inches, so they keep their size and their place whatever paper is chosen. Drag the map to pan it and roll the wheel to zoom; the sheet is laid out again with the map where you left it.
