style.json - edit it; the map follows
Whatever the file format, the server reads it through the matching FeatureSource; the same three style layers draw every one of them. Drawn by the browser, the source is cut into vector tiles at tiles/vector-<format>/. Drawn by the server, the style is handed over and CpuTileRenderer draws it into raster tiles - the same document either way, edits included.
