A feature source of your own

SimpleCsvFeatureSource, in the server code beside this page, derives from FeatureSource and overrides one method: GetAllFeaturesCore reads a CSV of latitude, longitude lines. Everything else - the projection converter, the bounding box, the tile cutting at tiles/csv-route/ - is inherited, so the map treats it like any shapefile, and so does the server when it is handed the style to draw into raster tiles itself.
