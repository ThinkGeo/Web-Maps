Reproject your data

One class does both jobs. A ProjectionConverter turns coordinates from one system into another; put it on shapes you hold yourself and they come back in the map's system, or put it on a layer's FeatureSource and every feature it ever hands out arrives converted, so the tiles are cut and the style drawn as if the file had always been Web Mercator.

Frisco's zoning is stored in Texas state plane feet (EPSG:2276). The only line about projection is the converter on its FeatureSource; from then on the source hands out metres, the tiles are cut at tiles/zoning/ and the style draws them, with nothing here knowing the file was ever anything else.
