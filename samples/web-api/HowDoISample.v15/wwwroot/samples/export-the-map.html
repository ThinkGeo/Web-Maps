Export the map

Frisco's zoning over the basemap, out of the map as a file. The map in the file is drawn either by the browser - its own canvas read back, exactly what is on screen, tilt and all, at screen resolution - or by the server, which draws the view again with no map control at all: the basemap's vector tiles through MvtTilesAsyncLayer, the zoning from its shapefile by the same style.json this page draws it with, into a picture of any width or as vector paths and glyphs that print sharp at any size. A PDF page - title, map, footer - is always made on the server by PdfGeoCanvas; the browser's map goes on it as a picture. The file is kept on the server for a few minutes and fetched from export/{id}.
