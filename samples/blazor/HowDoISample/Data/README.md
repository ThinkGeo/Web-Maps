# Sample data

Where the data under this folder comes from.

| data | used by | source |
|---|---|---|
| `Shapefile/Countries02` | Render Based on Rules, Create a Multi-Column Text Style | World countries with ISO codes and currency, ThinkGeo sample data |
| `Shapefile/WorldCapitals` | Create a Multi-Column Text Style | World capitals with population, ThinkGeo sample data |
| `usStatesCensus2010` | US Demographic Map | US states with US Census attributes, ThinkGeo sample data |
| `Shapefile/USStates_3857` | Display Dot Density, Dynamic Rendering | US states with 1990 census attributes, ThinkGeo sample data, Web Mercator |
| `Csv/historical_state_population_by_year.csv` | Dynamic Rendering | US Census Bureau state population estimates, one line per state and year (public domain) |
| `Shapefile/Parks`, `Streets`, `Hotels`, `Schools`, `Zoning`, `Hike_Bike`, `FriscoCityLimitsDivided` | Render Points, Lines and Polygons, Shapes & Spatial Queries, Hatch Styles, Migrate a Classic Layer, Setting the Projection of a Layer, Vector File Formats | City of Frisco, Texas open data (EPSG:2276) |
| `Shapefile/Frisco_Coyote_Sightings` | Heatmap | City of Frisco coyote-sighting reports (EPSG:2276); reporter names and contacts removed, only the sighting attributes remain |
| `Kml/Frisco.kml`, `Tab/City_ETJ`, `TinyGeo/Zoning.tgeo`, `FileGeoDatabase/zoning.gdb` | Vector File Formats, Databases | The same City of Frisco open data in KML (Web Mercator), MapInfo TAB, TinyGeo and Esri file geodatabase form |
| `Gpx/Hike_Bike.gpx` | Vector File Formats | Forty Frisco trails from `Hike_Bike.shp`, written as GPX tracks |
| `GeoJson/pittsburghpacity-designated-historic-districts.geojson` | Vector File Formats | City of Pittsburgh designated historic districts, Western Pennsylvania Regional Data Center open data |
| `S57/US1GC09M` | Vector File Formats | NOAA electronic navigational chart US1GC09M, Gulf of Mexico (public domain) |
| `SQLite/frisco-restaurants.sqlite` | Databases | Frisco restaurants, ThinkGeo sample data |
| `GeoPackage/mora_surficial_geology.gpkg` | Databases | Mount Rainier surficial geology, US Geological Survey / National Park Service (public domain, EPSG:26910) |
| `Csv/Frisco_Mosquitos.csv` | Isolines, Vector File Formats | Mosquito trap counts around Frisco, Web Mercator |
| `Csv/vehicle-route.csv` | Vehicle Navigation, Custom Feature Sources | A GPS trace through Lower Manhattan |
| `Ndfd/ds.wspd.tif`, `ds.wdir.tif` | Wind as a Vector Field | NOAA National Digital Forecast Database wind speed and direction, converted from GRIB (public domain) |
| `OpenDrive/` | Lane-Level Navigation | DLR HD map of Wolfsburg, CC BY 4.0 - see `OpenDrive/README.md` |
| `GeoTiff/World.tif`, `World.ecw` | Project a Raster, Raster File Formats | ThinkGeo sample world imagery |
| `GeoTiff/m_3309650_*.tif`, `Jpg/m_3309650_*.jpg` | Raster File Formats | USDA National Agriculture Imagery Program aerial photo of Frisco, 2016 (public domain) |
| `Shapefile/Frisco 2010 Census Housing Units` | Color Utilities | Frisco census block groups with 2010 housing-unit counts, City of Frisco open data (EPSG:2276) |
| `Pmtiles/frisco.pmtiles`, `style.json` | Offline Tiles | Frisco cut from Protomaps (OpenStreetMap data, ODbL) with the Protomaps light style |
| `Mbtiles/maplibre.mbtiles`, `style.json` | Offline Tiles | The MapLibre demo tiles of the world (Natural Earth, public domain) with the MapLibre demo style |
| `Data.xml` | Draw and Modify Geometries | Hand-drawn sample shapes |
