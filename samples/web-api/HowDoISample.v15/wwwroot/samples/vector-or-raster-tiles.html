Vector tiles or raster tiles

One style.json - Frisco's zoning, parks, trails, streets and schools, as FeatureLayerTranslator wrote it from five classic layers - and one server, delivering it two ways. Left: the data cut into vector tiles at tiles/translated/ and the document drawn by the browser. Right: the same document handed to the server at samples/tiles/style, drawn there by CpuTileRenderer over the same shapefiles into raster tiles at raster/style-…/, which the browser only shows. Both maps look at the same place; move either one.

What to look for. A colour: the left map redraws from the data it already has, while you drag; the right sends the changed document to the server once you let go and waits for tiles drawn again. Half a zoom level: the left stays crisp, the right is a picture stretched between two levels. A turn: the left's labels stay upright, the right's turn with the map. What each side fetched is counted at the bottom of each map.
