Basemaps from a service

Vector styles
Raster tiles

A vector basemap is a style URL: ThinkGeo Maps' light and dark are two styles over the same keyed tiles, and Mapbox, Esri or TomTom are their style URL with your key. A raster basemap is an XYZ address declared as a raster source, which is how Azure Maps, Google Maps, HERE and the rest are served too. The browser fetches either; the server has no part in it.
