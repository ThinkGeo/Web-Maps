This page's map is OpenLayers: its view can be any projection proj4 knows, where MapLibre draws Web Mercator only. In the browser, the tiles arrive in Spherical Mercator and OpenLayers warps each one - so the poles, which Mercator never had, stay empty. On the server, the layer is drawn straight into the target projection's own tile grid by GdalProjectionConverter - the GeoTIFF is read there from its WGS84 file and reaches the poles - and the browser only shows the tiles.
